# Open Caption

一款在电影院用手机横屏观看双语字幕的静态网页。当前目标影片是 *You Can See Everything* (2026)，片长暂按发行方 A24 标注的 2 小时 55 分钟设置；载入字幕后若最后一句更晚，会自动延长时间轴。

## 使用

1. 在手机打开网页，进入「字幕与设置」，分别导入英文和中文字幕的 `.srt` / `.vtt`，或者导入双语 `.json`。
2. 电影开始时点「开始」。若已经开映，拖动时间轴或点「跳到时间」。
3. 字幕太早出现，点 `−0.5s` / `−2s`；字幕太晚出现，点 `+0.5s` / `+2s`。校准会保存在本机。
4. 第一次联网打开后，应用外壳可离线使用。导入的字幕存在浏览器本地存储中；建议入场前用飞行模式测试一次。

双语 JSON 格式：

```json
{
  "duration": 10500,
  "cues": [
    {"start": 1.2, "end": 3.4, "en": "English dialogue", "zh": "中文翻译"}
  ]
}
```

目前仓库没有内置影片字幕。该片仍在院线上映；截至 2026-10-20，检索到的字幕聚合页面未提供可核验的完整英文对白和时间码。请勿把无关影片的字幕或自动生成的占位文件误当作正式字幕。拿到可信英文 SRT/VTT 后，可按故事背景逐句翻译、人名保留英文，并将核验后的双语 JSON 放入仓库。

## 开发与发布

无需安装依赖：`python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。运行 `npm test` 检查字幕解析、配对和时间轴。推送到 `main` 会触发 `.github/workflows/pages.yml` 的 GitHub Pages 部署；仓库的 Pages Source 需设为 **GitHub Actions**。
